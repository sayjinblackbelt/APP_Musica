# 05 — Materiais dos Usuários

Área destinada a materiais demonstrativos da experiência do aluno/usuário.

## Direção visual

Os materiais devem seguir a identidade do APP Música:

**Sofisticado · Editorial · Autoral · Musical**

Referência criativa e direção de arte: **NEXA — Studio**.

Aplicar de forma consistente:

- logo oficial do APP Música;
- personagem/avatar pixel-art com barba quando pertinente;
- preto editorial, off-white, laranja e violeta de apoio;
- Space Grotesk para títulos;
- DM Sans para textos;
- grids, espaço negativo e composição editorial;
- elementos musicais abstratos em vez de excesso de ícones decorativos.

## Conteúdos

Exemplos futuros:

- orientações de acesso;
- materiais de apoio;
- exercícios;
- guias de estudo;

- peças de divulgação.
