# Identidade visual — Pixel Art

## Decisão

Foi criada uma identidade visual autoral em pixel art para o protótipo APP Música, com duas aplicações na mesma composição:

- versão de marca/projeto: personagem tocando violão, nome APP Música e assinatura;
- versão de ícone: aplicação compacta para representar o futuro aplicativo.

A identidade mantém a direção visual já adotada no protótipo: azul-marinho escuro, laranja quente, branco/creme e linguagem musical.

## Uso previsto

A identidade deve ser utilizada de forma consistente onde agregar valor, evitando excesso de elementos decorativos.

### Prioridade alta

1. Logo/assinatura no cabeçalho da aplicação.
2. Logo no rodapé.
3. Ícone/favicon do projeto.
4. Ícone do futuro PWA/aplicativo.
5. Tela ou card de apresentação do projeto.

### Prioridade média

- Área Sobre.
- Materiais didáticos digitais.
- Capas de vídeos e aulas.
- Materiais para usuários.
- Documentação visual do projeto.
- Apresentações futuras.

## Regra de consistência

A pixel art passa a funcionar como elemento de identidade, não como ilustração obrigatória em todas as telas. Em telas funcionais como Agenda, Aula e Evolução, deve prevalecer a clareza da informação.

## Status

A arte foi gerada e aprovada conceitualmente nesta etapa. A inserção do arquivo raster/binário original no repositório e a aplicação global no HTML ficam registradas como próximo passo técnico, pois a integração atual via GitHub exige upload de arquivo binário que não está disponível pelo conector utilizado nesta sessão.

Até essa integração, não substituir a identidade visual atual por placeholders.

## Privacidade

A arte não contém nome de colaborador, dados pessoais ou informações reais de alunos. Pode ser utilizada no protótipo público como identidade visual autoral do projeto.
