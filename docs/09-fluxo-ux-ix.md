# Fluxo UX/IX — Jornada do aluno

A jornada principal será validada em duas passagens:

1. **Fluxo principal:** Home → Serviço → Cadastro → Agendamento → Confirmação → Área do aluno.
2. **Estados:** retorno, erro, indisponibilidade, validação e preservação de contexto.

O objetivo é reduzir dúvidas, cliques desnecessários e decisões ambíguas antes de iniciar o painel do educador.
