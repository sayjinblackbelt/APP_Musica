# Critérios UX e IX — Protótipo

## UX

- A interface deve explicar o que acontece sem exigir conhecimento prévio.
- Cada etapa deve ter um objetivo principal e um próximo passo evidente.
- O aluno deve conseguir comparar serviços sem sobrecarga cognitiva.
- Formulários devem solicitar somente dados necessários para a etapa atual.
- A agenda deve privilegiar leitura rápida e escolha simples.
- A Área do aluno deve priorizar próxima aula, pendências e próximos passos.
- A experiência deve ser responsiva e acessível.

## IX

- Toda ação relevante deve gerar feedback imediato.
- Mudanças de estado devem ser visíveis e compreensíveis.
- Voltar deve preservar o contexto sempre que possível.
- Ações destrutivas ou irreversíveis devem exigir confirmação.
- Estados vazio, carregando, sucesso, erro e indisponibilidade devem ser planejados.
- O sistema deve diferenciar claramente simulação de operação real.

## Regra de passagem

A jornada do aluno deve ser testada ponta a ponta antes de iniciar o painel do educador.
